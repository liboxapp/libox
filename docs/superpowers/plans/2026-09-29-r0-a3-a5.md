# A3–A5 — plan de ejecución

**Objetivo:** corregir los límites confirmados del harness antes del canon L3 V8.
**Spec:** [programa R0](../specs/2026-09-25-habilitar-r0-design.md).
**Arquitectura:** controles locales heurísticos más CI obligatorio; auditorías
sobre snapshots separados, evidencia inmutable y dependencias fijadas.

**Ejecución:** tareas independientes por archivo, integración y revisión automatizada.

`session_status.py`, tests de hooks y timeouts en `.claude/settings.json`.

- [ ] Resolver ruta léxica y destino real sin ejecutar comandos del usuario.
  Aplicar E1/E2/E3 sobre ambas rutas; E4 protege archivos del OS con escape avisado.
- [ ] Analizar comandos con shlex: opciones globales Git, refspecs a main,
  mensajes por archivo/trailer, pathspec, `add && commit` y correo efectivo.

  Limitar duración total; el hook de estado no infiere cierre por regla ausente.
- [ ] Ejecutar pruebas rojas antes de implementar, luego suite completa de hooks.

## Casos de revisión

- Symlink hacia dentro/fuera del repo y archivos nuevos dentro de directorios enlazados.
- Git global `-C`, `-c`, pathspecs y correo por entorno; nunca ejecutar el shell analizado.
- Fallos de JSON, Git y verificador: aviso visible; duración menor que timeout del hook.
- Auditoría concurrente, resume con SHA distinto, informe existente y revisión parcial.
- Datos externos con saltos de línea, controles y contenido con apariencia de instrucciones.
