# C1 — plan de ejecución

**Objetivo:** preparar una decisión verificable bajo US$250/mes y completar el
borrador L3 y reconciliar Cowork sin modificar el canon ni generar código de zonas críticas.
**Arquitectura:** monolito modular Next.js/TypeScript, PostgreSQL y workflows gestionados.
**Spec:** [programa R0](../specs/2026-09-25-habilitar-r0-design.md).
**Paquete:** [C1 para decidir](../specs/2026-09-30-r0-c1-design.md).
**Delta recibido:** [reconciliación Cowork](../specs/c1-l3-v8/reconciliacion-linea-base.md).
**Ejecución:** investigación independiente por dominio y revisión automatizada;
revisión humana del desarrollo suspendida por instrucción de Diego.

## Restricciones globales

- Presupuesto inicial indicado: hasta US$250/mes, una persona actual.
- No editar documentos canónicos vigentes ni levantar el freeze antes de C2/D1.
- No generar implementación de dinero, sorteo, concurrencia ni incompatibilidades.
- No activar servicios, contratar planes o comprometer un gasto por redactar opciones.
- Mantener separación entre propuesta, proveedor elegido y evidencia ejecutada.
- Diego decide proveedores antes de C2; ASS-001 sigue abierta.
- Preservar acuerdos C1 y cambios locales; la fuente .NET no revoca TypeScript.
- Resolver identidad V8/V9 con evidencia de emisión; no renombrar por el nombre recibido.
- No ratificar porcentajes, plazos de fianza o canales por incorporarlos al plan.

## Foco de revisión

- Polling y cron sin compras deben aparecer en el cálculo de costos.
- PITR de DB no se presenta como copia de objetos ni SLA de toda la aplicación.
- Renovar tokens no cuenta como actividad humana para timeout interno.
- Un cron de un minuto no acredita cadencia de diez segundos.
- Inventario de rutas no se presenta como OpenAPI completo ni pruebas de contrato.
- Garantía no nula no demuestra cobertura; caja y mínimo de tickets deben ser coherentes.
- Bases, checkout, FSM y API deben comunicar el mismo desenlace de cierre.
- Sumas de historias, épicas, releases y trabajo humano deben partir de una tabla única.
